# Naman Saini — Portfolio Website 🚀

A modern, responsive, and high-performance personal portfolio built with **React**, **Vite**, **Tailwind CSS**, and **EmailJS**. Features a sleek dark theme, glassmorphism UI elements, interactive skill previews, dynamic contact forms, and an interactive AI mascot.

## ✨ Key Features

- 🎨 **Glassmorphism UI Design:** Modern dark-mode aesthetics with subtle neon glows and card backdrops.
- ⚡ **Lightning Fast:** Built with Vite and React for instant page loads and smooth transitions.
- 📱 **Fully Responsive:** Adaptive layouts optimized across Desktop, Tablet, and Mobile devices.
- 📩 **Working Contact Form:** Direct email delivery powered by **EmailJS** integration.
- 🛠️ **Interactive Skill Cards:** Dynamic visual previews and animated icons for core technical skills.
- 🐾 **Interactive Mascot (Patuti):** Custom floating mascot component for enhanced user interaction.

---

## 🛠️ Tech Stack

- **Frontend Framework:** React 18
- **Build Tool:** Vite
- **Styling:** Tailwind CSS, Custom Glassmorphism Styles
- **Form Handling:** EmailJS (`@emailjs/browser`)
- **Icons & Media:** Custom SVG Paths & Isometric Mockups

## 🚀 Getting Started Locally

### Prerequisites
Make sure you have **Node.js** (v18 or higher) installed on your system.

### Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/NamanSaini2007/portfolio.git
   cd portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```

4. Open http://localhost:5173 in your browser.
